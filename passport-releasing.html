User Management
Note: Only the supervisor account may create new users. Admin accounts can still edit and manage users but cannot create new accounts unless logged in as supervisor.
Backend warning: Database assignment will not be persisted unless the `app_users.allowed_databases` column exists in your backend schema.
ADMIN
Full system control with audit access.
  • Manage users, logs, and database settings
  • Create, edit, delete, and transfer records
  • Export manifests and released reports
USER
Operational database users with standard workflow access.
  • Scan and import entries
  • Export manifests and release records
  • Cannot delete or wipe full databases
VIEWER
Read-only access for monitoring and lookup.
  • Global Search only
  • No scanning, imports, exports, or edits
  • No database or user management
Assigned Database Visibility
Main databases are assigned per user. Users only see their allowed primary database(s) plus the shared status databases below.
  • Primary databases: ASEANA, POW
  • Shared status databases: Resolved, Suspended, Hold For Pick Up, Return to Origin, Active/Claimed
  • Example: alan is assigned to POW only and cannot access ASEANA.
